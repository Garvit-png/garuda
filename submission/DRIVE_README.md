# Garvit Gandhi: Dictionary App (Track 3)

I built a mobile-first, offline-capable dictionary web app on 60 entries: the 10 provided plus 50 that I added and validated. Search works in Devanagari and Roman: `धर्म`, `dharma`, `dharm` and `dharam` all open the same entry. Spellings not in the variant list are matched through a phonetic key, typos are tolerated, and English meanings are searchable too. It includes bookmarks, recently viewed words, a word of the day, Hindi text-to-speech and share links.
